# Escapade

Démo mono-fichier : swipe-to-match pour planifier un voyage de groupe.
Aucune requête réseau, aucune donnée ne quitte l'appareil.

- Trois destinations (Pays basque, Lisbonne, Kyoto), 33 lieux.
- Trois profils de vote simulés de façon déterministe ; un lieu « matche » à partir de 2 voix sur 3.
- Itinéraire généré par plus proche voisin (haversine), journée plafonnée à 330 min de visite.
- Carte schématique SVG, budget et distance à pied.

Ouvrir `index.html` dans un navigateur. Démo, pas un produit.
